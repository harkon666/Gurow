# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation needed |
| `needs-info` | `needs-info` | More information needed |
| `ready-for-agent` | `ready-for-agent` | Specified work ready for an agent to begin within its stated scope and gates |
| `ready-for-human` | `ready-for-human` | Human implementation required |
| `wontfix` | `wontfix` | Work will not be actioned |

Use these names when a skill refers to a triage role. Create a missing label when needed for an authorized tracker action, preserving existing labels. An accepted spec uses `ready-for-agent` without another triage interview.
