# Copy Skills and Tasks from the author's own content through the ordinary save

[ADR 0004](0004-scope-skills-and-tasks-to-learning-paths.md) makes reuse a copy with new logical IDs. This decision sets where a copy can come from and how it reaches its destination.

An Account copies from the content it authors: every Path of its Personal Workspace and, in each Coach Workspace it owns, every Path's open Draft and published Versions. An Enrollment is not a source, so a learner cannot copy a Coach's Skills or Tasks into a personal Path, and nothing of another Account is ever offered. The backend lists these sources for the signed-in Account; each source is then read through its existing owner-only read.

The copy is made in the destination editor, a personal Path or a Coach's Draft, and saved as an ordinary revision-checked save of that document ([ADR 0016](0016-save-editor-snapshots-with-revision-checks.md)); there is no separate copy request. Each copied Skill and Task gets a new ID in the browser, which the backend claims for the destination like any new Skill or Task, so a save reusing a source ID is refused. Prerequisites come along only between Skills copied together; a link to a Skill left behind would cross Paths or Versions, which a save refuses. Draft rules (Required or Enrichment Tasks with rewards, Optional Skills and XP Thresholds) are copied only from Coach content into a Draft; personal rewards and thresholds are learning records outside the document and stay behind, and personal content copied into a Draft starts with the rules of a new Skill or Task. No link to the source is stored.

Saving the copy through the ordinary save keeps one write path for Path content, so a copy gets graph validation, revision checks, kept-work recovery and the published-content guard without new backend rules, at the cost that the backend cannot tell a copy from content typed by hand. Storing no provenance follows from copies being independent and avoids recording one Workspace's content in another, at the cost of not showing where a copy came from. Excluding enrolled Versions as sources keeps a Coach's content with the Coach until a sharing decision is made.
