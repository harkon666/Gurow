# Limit Enrollment data visibility to the learner and owning Coach

In the MVP, an Enrollment's progress, XP, Mastery, Submissions, and Review results are visible only to the learner concerned and the Coach who owns the relevant Coach Workspace. Other learners cannot view that data, including learners enrolled in the same Learning Path Version.

This establishes a clear privacy and authority boundary for individual learning records. Viewing peers' work, peer review, and leaderboards comparing learners are deferred, at the cost of fewer opportunities to learn from classmates' work or use shared rankings for motivation within the MVP.
