# Scope personal XP access checks to Learning Paths

In MVP personal mode, a Skill's XP Threshold uses only the user's XP from the Learning Path containing that Skill. XP from other personal Learning Paths and coach mode is excluded. This lets users configure each Path's progression independently, at the cost of previously earned XP elsewhere not satisfying access requirements when starting another Path. Users retain the ability to open a Skill explicitly through an Access Override.

Users set their own Task rewards and earn XP by marking Tasks complete, without mandatory evidence or self-review. Undoing completion removes the Task's reward through a recorded automatic correction; completing the Task again restores that reward without multiplying it. Personal Mastery remains independently declared and neither grants extra XP nor changes automatically with these Task actions. This keeps personal activity tracking lightweight while allowing the XP total used for a Path's access checks to decrease when completion is undone.

Changing a personal Task's configured reward immediately adjusts its XP contribution if the Task is complete, through a recorded correction for the difference. A change from 20 to 50 XP therefore adds 30 XP to the total; an incomplete Task continues to contribute zero. If completion is later undone or restored, the correction uses the current configured reward. This preserves users' control over personal rewards at the cost of reward edits changing XP and potentially Access after the work was completed.

Personal Access follows current Learning Path XP. Falling below a Skill's XP Threshold locks it again, including after work has begun, unless an active Access Override applies. Existing work and declared personal Mastery are preserved. This keeps configured thresholds consistent at the cost of undoing one Task's completion potentially requiring the user to explicitly override Access on another Skill to continue learning there.
