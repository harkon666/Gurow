# Validate required progression before publication

A coach-mode Learning Path Version can be published only when its progression rules allow the learner to complete every required Skill using Required Tasks on required Skills alone, without relying on Optional Skills, Enrichment Tasks, or Access Overrides. Validation must account for both Prerequisites and XP Thresholds: XP rewards become available only from Tasks whose Skills can already be accessed and whose work receives valid Approval. Rewards inside a locked Skill cannot fund its own unlock.

For example, if all accessible required work provides only 60 XP and the next required Skill needs 100 XP, rewards available solely through optional material cannot make the required route valid. This would make that material effectively mandatory despite its optional designation. A route that depends on an override to proceed also fails validation.

Publication is rejected when required progression is blocked, with an explanation identifying the affected Skills and unmet requirements. Coaches must adjust their requirements or rewards before publication, trading authoring flexibility for a required route that can be completed under its ordinary rules. This validation concerns the version's design; the existing rules for individual Approval Revocations, XP Corrections, and Access Overrides still apply during learning.
