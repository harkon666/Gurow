# Keep learners on the Learning Path Version they joined

In coach mode, a published Learning Path Version's learning content and rules are immutable. Every change, including typo corrections, is prepared in a Learning Path Draft and published as a new Version, while existing learners continue on the Version they joined. Their Mastery and Access still follow current evidence and applicable overrides under that Version's requirements. This preserves consistent learning and assessment content at the cost of managing multiple Versions and keeping even small corrections from automatically applying to existing Enrollments. Canvas Layout remains governed separately below.

For the MVP, each Enrollment stays on one Learning Path Version throughout its learning process, and new versions serve new Enrollments. Migration of an existing Enrollment and its progress between versions is deferred because changed Tasks and Prerequisites would require rules for which earlier evidence remains applicable; coaches therefore cannot move an ongoing class to a newer version while carrying its progress across.

A Coach's Enrollment Invitation targets exactly one published Learning Path Version and is addressed to a specific email address. Only an Account with that matching email verified may accept it. When accepted, the learner is enrolled in the offered Version without automatically becoming a participant in other Learning Paths in the same Coach Workspace. This makes the recipient, scope, and learning Version explicit, at the cost of requiring the recipient to use the matching verified Account and requiring separate invitations for additional Paths.

The Coach may open or close a published Version to new Enrollments independently of publication. While enrollment is closed, invitations not yet accepted cannot create new Enrollments; existing Enrollments continue under their current status. This lets the Coach stop admitting new learners without disrupting existing participants, at the cost of managing admission separately from publication.

For the MVP, an Account has at most one Enrollment in any given Learning Path Version. Accepting another invitation to the same Version uses that existing Enrollment without resetting its progress or creating a separate XP total. Invitation acceptance does not reactivate an inactive Enrollment; that requires the owning Coach's explicit [Enrollment Reactivation](0014-preserve-learning-history-when-deactivating-enrollments.md). This keeps one coherent learning history per Account and Version, at the cost of not supporting separate attempts from the beginning with independent progress on the same Version.

Each Learning Path Version has its own Canvas Layout, which a coach may update independently when only card positions change, without creating a new learning version. Learners see the latest layout for their enrolled version when reopening the Learning Path. This allows readability improvements for ongoing learners at the cost of familiar card positions changing even while learning requirements remain stable.

In MVP coach mode, learners may pan, zoom, and select Skills, while changing card positions is reserved for the coach. Learner-specific layouts are deferred, giving coach and learners a shared arrangement for discussion at the cost of learners being unable to rearrange cards to suit their own preferences.
