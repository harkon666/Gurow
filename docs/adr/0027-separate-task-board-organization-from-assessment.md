# Separate Task Board organization from assessment

Task Boards organize one Skill's Tasks within personal ownership, a Coach's Learning Path Draft, or a Learner's Enrollment; learner columns and positions are independently customizable per Enrollment rather than shared with the Coach or other learners. A personal board has one designated Completion Column tied to existing completion and XP rules, whereas Coach Draft columns express material readiness and learner columns express working progress without triggering Submission, Approval, Mastery, or automatic moves after Review. This preserves personal workflow freedom and immutable learning/evidence contracts, at the cost of showing review status separately from board placement and keeping personal completion changes consistent with their column membership.
